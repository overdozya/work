# 작성자의 자체 검토

이 문서는 구현한 작성자가 직접 수행한 자체 검토입니다. 다른 리뷰어가 검토한 것으로 표시하지 않습니다. 파일별 체크리스트는 [PR 초안](PR.ko.md)에 기록했습니다.

## 확인한 결과

- 사람 검토와 명시적 승인이 없으면 훈련에 들어갈 수 없습니다. 검토자가 수정 필요를 기록하면 승인할 수 없습니다.
- 인터뷰 재추출과 새 반례는 승인을 해제합니다. 재승인해도 이전 승인 ID를 가진 훈련은 힌트·제출을 이어갈 수 없습니다.
- 원문 인용은 실제 원문 부분 문자열이어야 하며 AI 일반화에는 원문 인용을 붙일 수 없습니다. 그래프의 모든 노드가 연결되고 다섯 판단 요소를 포함해야 합니다.
- 채점의 근거는 학습 답안의 정확한 인용이어야 합니다. 점수는 정수 0~4 범위이고 각 차원이 중복되지 않아야 합니다. 답안이 다른 선택을 해도 타당한 근거를 인정하도록 요청합니다.
- 정답 참고 메모·평가 기준·아직 열지 않은 힌트는 훈련 응답에서 숨깁니다. 힌트 수는 서버에서만 증가합니다.
- 동일 세션의 재제출은 막고, 서로 다른 문제의 연속 수행 두 번으로 단계가 상승합니다. 도움을 받은 수행과 고정 데모는 단계 상승 근거로 쓰지 않습니다.
- 원문 지도 버전이 바뀌면 학습 근거는 새 버전에서 모으되, 이전 기록은 내보내기에 보존합니다.
- API 키는 URL·브라우저·응답·상세 오류 로그에 포함하지 않습니다. CSP, HTML escape, 루프백·Origin·Host·토큰 검사를 확인했습니다.
- 테스트에서 드러난 SQLite 연결 정리 문제를 수정했습니다. 연결은 트랜잭션 종료 후 명시적으로 닫힙니다.
- 사용자 런타임 DB와 브라우저 검사 DB를 분리했습니다. 브라우저에 입력한 검토자 ‘브라우저 자동화 검증’은 격리된 검증 데이터에만 남습니다.

## 검증

`make check`의 테스트 31개와 JavaScript 문법 검사가 통과했습니다. Chrome 브라우저 검증에서 지도·승인·반례·훈련·힌트·데모 평가 제외·내보내기·모바일 다섯 화면과 모달이 통과했고 콘솔 오류가 없었습니다. 데스크톱 판단 지도와 홈, 모바일 홈의 렌더링도 직접 확인했습니다. `.local/`의 이미지와 내보내기 JSON은 커밋 제외입니다.

## 남은 우려

실제 Gemini API 키가 없어 실호출, 계정별 모델 사용 가능 여부, 실제 생성 품질은 확인하지 못했습니다. 전송 계약과 실패는 가짜 전송 계층으로 검증했습니다. 실제 모드의 인터뷰 품질·평가 편향·시나리오 다양성은 전문가 사례로 별도 확인해야 합니다.

회상 진술을 작업물과 대조하는 수집·검증 기능이 아직 없습니다. 생성된 지도의 스키마·인용 검사를 통과해도 올바른 일반화라는 보장은 없습니다. 이를 사람 검토와 잠정적 AI 평가로 표시했습니다. 교육 효과 입증을 위한 문서·RAG·훈련 비교군과 독립적인 전문가 채점도 아직 구현하지 않았습니다.

현재 로컬 데모 범위에서 작업을 막는 추가 발견은 남지 않았습니다. 실제 Gemini 품질 검증과 외부 운영을 위한 권한·데이터 정책은 후속 확인 사항입니다. 공개 대상은 `overdozya/work`이며 기존 원격 main의 초기 커밋을 보존한 `feat/judgment-atelier` 브랜치에서 변경을 준비했습니다. 공개 README에서 개인 절대 경로와 원격 미지정 문구를 제거하고 복제·실행 방법을 명시했습니다. 추적 파일에 실제 API 키·데이터베이스·.local·사용자 런타임 상태가 없음을 점검했습니다. 소스 저장소 공개와 외부 서비스 배포는 별개이며 현재 실행 범위는 로컬입니다.

## 롤백

공방 프로세스를 종료하고 이전 코드로 돌아갑니다. `.local/`과 `.env`는 삭제하지 않습니다. 기존 Skalapse 서비스와 작업 중인 데이터 파일은 수정하지 않았습니다.
