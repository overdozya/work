# ‘설명하는 AI’와 ‘판단하게 만드는 AI’를 비교하기

현재 구현은 가설을 실험할 수 있는 시작점입니다. 학습 지도나 AI 평가만으로 교육 효과가 입증되지는 않습니다.

## 작은 실험

실제 미술·디자인 사례 3~5개를 선정합니다. 목적, 실제 작업물, 관찰 기록, 대안, 선택, 실패 사례, 예외를 전문가 인터뷰로 확보합니다. 현재 제공하는 세 사례는 데모이며 실제 연구 자료로 간주하지 않습니다.

전문가가 인터뷰에 등장하지 않은 평가 상황과 기준을 미리 작성합니다. 학습자에게 제공하는 자료와 평가 문제는 분리하고 문제 생성·채점에 사용되는 모델에도 평가 문제를 사전에 노출하지 않습니다. 최종 결과는 AI 점수와 별도로 사람 전문가가 평가합니다.

| 비교군 | 학습 방법 | 구현 상태 |
|---|---|---|
| A | 전문가의 일반 교육 문서 | 후속 실험 |
| B | 동일 인터뷰를 검색하는 RAG 챗봇 | 후속 실험 |
| C | 조건부 판단 지도·반례·도움 감소 훈련 | 현재 프로토타입 |

각 군의 교육 시간, 사례 수, 인터뷰 자료량을 맞춥니다. 가능하면 학습자를 무작위 배정하고 채점자는 어느 교육군인지 모르게 평가합니다. 소수 참가자의 탐색적 파일럿이면 효과 크기의 불확실성과 사전 경험 차이를 함께 기록합니다. 참가자 동의와 데이터 처리 범위도 정합니다.

## 주요 평가

- 처음 보는 과업에서 중요한 단서와 판단을 바꾸는 조건을 찾는가.
- 둘 이상의 대안을 목적·환경과 연결해 비교하는가.
- 선택한 조치와 관찰 단서 사이의 인과를 설명하는가.
- 원래 규칙을 적용할 수 없는 경계를 발견하는가.
- AI 도움 없이 수행할 수 있는가. 일정 기간 후에도 유지되는가.

전문가의 결론에 무조건 동의하는 것을 성공으로 삼지 않습니다. 표현 의도·취향·객관적으로 확인 가능한 관찰을 구분하고, 다른 선택도 근거가 타당하면 인정합니다. 기준은 학습 전 고정하고 채점자 간 일치와 불일치를 남깁니다.

## 현재 내보내기에서 얻을 수 있는 것

원문·인터뷰·지도·규칙·승인 메모, 당시 시나리오와 기준, 학습 답안, 확신도, 열린 힌트 수, 차원별 모델 평가와 인용, 생성·검토·승인·제출 이벤트를 확인할 수 있습니다. 모델 점수와 확신도가 어긋나는 사례를 다음 인터뷰와 전문가 재평가의 후보로 사용할 수 있습니다.

아직 사용자/비교군 식별, 사전·사후 시험, 무작위 배정, 눈가림 전문가 채점, 지연 재시험, 교육 시간 자동 측정은 구현하지 않았습니다. 내보내기를 실제 효과 비교 데이터셋이라고 부르지 않습니다.

## 실패를 분리하기

1. 추출 실패: 중요한 목적·조건·근거가 지도에서 빠진다 → 원문·작업 기록과 지도 비교.
2. 일반화 실패: 한 사람의 회상을 모든 상황의 규칙으로 만든다 → 반례와 복수 전문가 검토.
3. 훈련 실패: 설명은 이해하지만 새 상황에서 단서를 못 찾는다 → 관찰·대안 비교를 분리해서 연습.
4. 평가 실패: 좋은 표현이나 전문가와 같은 선택만 고득점이다 → 사람 채점과 AI 채점 비교.
5. 전이 실패: 훈련에서는 성공하지만 도움 없는 과업에서는 실패한다 → 별도 독립 수행 과제·지연 평가.

다음 개발의 우선순위는 실제 작업물과 관찰 기록을 붙이는 기능입니다. 예쁘게 그린 지도보다 ‘무엇을 봤길래 판단이 바뀌었는가’를 확인할 수 있어야 합니다.
