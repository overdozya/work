# feat: Gemini 기반 전문성 전이 실험 ‘판단 공방’

## 사용자에게 보이는 결과

실제 작업 사례를 입력하면 Gemini가 상황·단서·선택·근거·예외를 판단 지도로 구성합니다. 노드를 선택해 원문 근거를 확인하고, 추가 인터뷰로 지도를 수정할 수 있습니다. 조건 하나를 바꿔 반례를 만들고 사람이 적용 경계를 검토·승인하면 새로운 상황에서 판단을 연습합니다. 힌트를 점차 줄이고 선택의 근거·확신도·수행 기록을 학습 지도와 내보내기로 남깁니다.

디자인 고정 예시 세 개로 키 없이 흐름을 체험할 수 있습니다. 데모 생성 결과는 실제 Gemini 응답과 구분하며 데모 답안에는 숙련도 점수를 부여하지 않습니다. 한국어 UI와 데스크톱·모바일 레이아웃을 제공합니다.

## 아키텍처·보안 결정

- Skalapse 안의 `judgment-atelier` 폴더를 독립 Git 저장소로 구성합니다. 부모 프로젝트의 API·데이터·UI에 의존하지 않습니다.
- Python 표준 라이브러리 HTTP 서버와 SQLite, 로컬 HTML/CSS/JavaScript를 사용해 설치 없이 작은 실험을 실행합니다.
- 로컬 LLM 대신 서버 전용 Gemini REST 어댑터를 사용합니다. JSON schema와 원문/답안 인용, 지도 연결, 평가 차원을 애플리케이션에서 다시 검증합니다.
- 상태·승인·힌트 사용·단계 상승은 서버가 결정합니다. 인터뷰 또는 반례 갱신은 승인을 해제하고 승인 ID가 다른 훈련은 무효화합니다.
- 127.0.0.1 바인딩, Host/Origin·CSRF 토큰·입력 크기·정적 파일 목록·CSP·HTML escape를 적용합니다. 키는 Google 요청 헤더에만 보냅니다.
- `.env`, `.local`, SQLite, 스크린샷과 테스트 내보내기는 커밋하지 않습니다.

## 검증 증거

- `make check`: Python 테스트 31개 통과, JavaScript 문법 검사 통과.
- `make browser-check`: Chrome에서 지도 원문 확인, 미승인 훈련 차단, 반례 생성, 사람 검토·승인, 힌트 열기, 답안 제출, 데모 평가 제외, JSON 다운로드 통과.
- 390px 모바일에서 다섯 화면의 가로 넘침 없음, 새 사례 모달 확인, 브라우저 오류 없음.
- SQLite 재열기·버전 충돌·가짜 인용·평가 근거·재승인 후 오래된 훈련·지도 변경 후 근거 초기화·독립 단계 힌트 차단을 확인.
- Gemini 전송 계약·헤더 키·잘린 JSON·잘못된 스키마·429 재시도·403 즉시 실패를 가짜 전송 계층으로 확인.
- 실제 Gemini 호출: API 키 미설정으로 미검증.

## 남은 위험과 범위

AI 점수와 인터뷰 추출은 검증된 숙련도 척도나 실제 사고 과정의 복원 결과가 아닙니다. 관찰 기록·작업물 대조와 전문가 채점이 추가로 필요합니다. 작업물 이미지·영상, 복수 전문가 비교, 규칙 직접 편집, 문서/RAG/훈련 비교 실험은 후속 범위입니다. 동일 시나리오 텍스트는 막지만 의미 중복 검출은 없습니다. 네트워크 단절 후 생성 요청의 완전한 멱등성·사용량 계측은 미구현입니다. 외부 공개용 인증과 조직 권한은 없습니다.

## 롤백·운영

원격 저장소는 [overdozya/work](https://github.com/overdozya/work)입니다. 기존 원격 main의 초기 커밋을 바탕으로 `feat/judgment-atelier` 브랜치를 구성하고 README에 복제·실행·설정·설계·검증 방법을 정리했습니다. 이 PR은 독립 공방 프로젝트의 소스 공개와 로컬 실행을 위한 변경입니다. 검증을 통과한 후 main에 반영하며, 기존 Skalapse의 프로덕션 병합·배포 대상은 아닙니다.

문제가 생기면 공방 서버만 종료하고 이전 소스 커밋으로 돌아갑니다. SQLite 데이터와 `.env`는 보존합니다. 데이터 백업은 서버 종료 후 `.local/` 폴더를 복사합니다. 원래 Skalapse 서비스와 런타임 데이터는 수정하지 않습니다.
